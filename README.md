# S. Prince Management Tool

Tenders, projects, subcontractors, employees, GST and daily work for **S. Prince Hightech Pvt. Ltd.**
Front-end MVP with deterministic mock data: no backend and no login (a role switcher stands in for auth).

```bash
npm install
npm run dev          # http://localhost:3000
npm run lint
npm run typecheck
npm run seed:check   # builds the mock seed and verifies integrity and client requirements
```
